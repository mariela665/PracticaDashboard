CloudMetrics - Dashboard SPA Responsivo

Interfaz web responsiva para el monitoreo de servidores e instancias cloud
Características Principales

Diseño Mobile-First: Adaptable a celulares y escritorio usando CSS Grid  y Flexbox.

Arquitectura en 3 Zonas:

Navegación: Header fijo con cambio de tema y menú lateral desplegable en móvil.

Contenido: Tarjetas con métricas principales y lista de servidores activos.

Interacción: Panel lateral  y ventana Modal para confirmar reinicios.

Estados de Control: Botones e inputs con estilos para Default, Hover, Focus, Disabled y Loading .

Modo Claro y Oscuro: Implementado con variables CSS y detección automática del sistema.

Accesibilidad:Cierre de ventanas emergentes con la tecla Escape.

Estructura del Proyecto

index.html - Estructura principal de la aplicación.

variables.css - Paleta de colores y variables para modo claro/oscuro.

layout.css - Estilos de cuadrícula responsiva (Grid y Flexbox).

Componenetes.css - Estilos de tarjetas, botones, estados, drawer y modal.

app.js - Lógica para abrir/cerrar menús, cambiar tema y simular tiempos de carga.

Cómo visualizarlo

Descarga o clona el repositorio.

Abre el archivo index.html en cualquier navegador web.
